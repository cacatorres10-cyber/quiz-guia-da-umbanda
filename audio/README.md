# audio/

Coloque aqui a música de fundo do quiz.

Nome esperado pelo código: **`ori-background.mp3`**

Para usar outro nome, ajuste `MUSICA` no `QUIZ_CONFIG`, no topo do `index.html`.

Dicas:

- MP3, mono ou estéreo, algo em torno de 96–128 kbps já basta (é música de fundo,
  toca a 15% de volume).
- Deixe o arquivo abaixo de ~3 MB para não pesar no celular.
- Use uma faixa que você tenha direito de usar.

Enquanto o arquivo não existir, o botão de música some sozinho da página.
